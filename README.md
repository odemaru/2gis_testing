[![tests](https://github.com/odemaru/2gis_testing/actions/workflows/tests.yml/badge.svg)](https://github.com/odemaru/2gis_testing/actions/workflows/tests.yml)

сервиса избранных мест, оформить баг-репорт и покрыть метод автотестами.

## Запуск

Требуется Python 3.12+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest
```

Другие варианты запуска:

```bash
pytest -v                          # с именами тестов
pytest --log-cli-level=INFO        # с логом запросов и ответов
pytest tests/test_known_bugs.py    # только проверки найденных дефектов
pytest --base-url=https://example.com/v1   # другой стенд
```

Тесты обращаются к внешнему стенду, поэтому нужен доступ в сеть.

## Устройство тестов

**Транспорт отделён от клиента.** Все запросы идут через `Http.request()`.
Если понадобится заменить `requests` на другую библиотеку, менять придётся
один файл.

**Клиент не проверяет ответы.** `AuthApi` и `FavoritesApi` только формируют
запрос и возвращают ответ как есть. Все проверки лежат в тестах, поэтому тест
падает на строке с assert, а не внутри клиента.

**Схемы описывают весь контракт.** `FAVORITE_SCHEMA` задаёт не только типы
полей, но и диапазоны координат, длину названия, список цветов и запрет
неописанных полей. Проверка `format` включена явно через `FormatChecker`.
Без него `"format": "date-time"` в jsonschema ничего не проверяет.

**Токен запрашивается на каждый тест.** У фикстуры `token` скоуп `function`.
Токен живёт около двух секунд, поэтому общий на всю сессию токен протух бы
уже на втором тесте.

**Дефекты закреплены тестами.** Каждый дефект описан тестом в
`test_known_bugs.py`. Тест проверяет поведение, которого требует документация,
и помечен `xfail(strict=True)` со ссылкой на баг-репорт. Пока дефект
воспроизводится, прогон остаётся зелёным. Если дефект исправят, тест перейдёт
в `XPASS` и уронит сборку, так что изменение не пройдёт незамеченным.

Каждый автотест состоит из двух шагов, как требует задание: формирование
запроса к серверу и сравнение результата с ожидаемым значением тест-кейса.

## Стек

`pytest`, `requests`, `jsonschema` вместе с `rfc3339-validator`.
